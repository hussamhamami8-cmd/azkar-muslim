أذكار المسلم — قاعدة محتوى موسعة، إصدار مراجعة نهائية أولية

المصدر الأساسي للهيكلة والتحقق: الجامع الصحيح في الأذكار والأدعية التابع لمؤسسة الدرر السنية.
المشروع يضم الآن مواد مصنفة موضوعيًا، مع المصدر والدرجة/نوع المادة.
لا تُعرض المواد الموسومة (دعاء/أثر/سنة) على أنها أحاديث صحيحة مرفوعة.

ملاحظة مهمة: لأن المصدر المرجعي نفسه كتاب كبير من 896 صفحة ويضم 11 بابًا،
فالملف الحالي هو قاعدة موسعة وليست تفريغًا حرفيًا كاملًا لكل مادة في الكتاب.
قبل النشر العام ينبغي إجراء تدقيق نصي أخير لكل عنصر ومطابقة ألفاظه وأعداده مع المصدر.
