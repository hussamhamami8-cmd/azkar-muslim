# أذكار المسلم — V2 Final

نسخة PWA عربية RTL تعمل محليًا وتدعم الاستخدام دون اتصال للمحتوى المحمّل مسبقًا.

## المزايا
- واجهة حديثة Mobile First + وضع ليلي.
- بحث عربي مع تطبيع الحروف.
- أقسام وقراءة وفواصل ومتابعة آخر قراءة.
- مفضلة، نسخ، استماع، وعدّ للذكر.
- تسبيح.
- مشاركة الذكر كصورة PNG محليًا مع دعم Web Share عند توفره.
- مواقيت الصلاة مجانية عبر AlAdhan مع تخزين آخر بيانات.
- تاريخ هجري عبر متصفح الجهاز.
- PWA + Service Worker + Offline cache.
- صفحة إدارة محلية للاستيراد والتصدير والمعاينة.
- لا توجد مفاتيح API سرية داخل المشروع.

## ملاحظات مهمة
مواقيت الصلاة والطقس/تحديد الموقع تحتاج اتصالًا عند أول جلب للبيانات، ثم يمكن الاستفادة من آخر بيانات محفوظة. إشعارات الخلفية التلقائية ليست مضمونة في كل متصفح؛ ذلك تحدده صلاحيات ونظام Android والمتصفح.

المحتوى الديني مأخوذ من الملف الأصلي المرفق بالمشروع ولم تتم إعادة تصحيحه علميًا هنا؛ يلزم مراجعة شرعية نهائية قبل النشر العام. تم استبعاد محتوى خاص غير مناسب للعرض العام من نسخة التطبيق.

للنشر على GitHub Pages: ارفع الملفات إلى مستودع، ثم فعّل Pages من إعدادات المستودع. لا تضع أي GitHub token داخل JavaScript.
